📖 ragent

Retrieval 检索链路

  • RetrievalEngine：检索总入口，负责根据意图组织知识库检索流程。
  • MultiChannelRetrievalEngine：多通道检索引擎，可同时从多个检索通道召回知识。
  • SearchChannel：检索通道抽象，主要包括意图定向检索和全局向量检索。
  • EmbeddingService：将用户问题转换为向量（QuestionVector）。
  • PgRetrieverService：使用问题向量在 pgvector 中执行向量相似度搜索。
  • TopK Chunk：从向量库中召回最相关的若干文本块（Chunk）。
  • DeduplicationPostProcessor：对召回结果进行去重，减少重复内容。
  • RerankPostProcessor：调用 Rerank 模型重新排序，提高检索结果质量。
  • 检索链路：Question → Embedding → Vector Search → TopK Chunk → Dedup → Rerank。
  • 作用：为后续 Prompt 构建提供最相关、最精炼的知识上下文。
💡 计网
  • NAT（网络地址转换）
    • 作用：将私有 IP 地址转换为公网 IP 地址，实现内网访问互联网。
    • 解决公网 IP 不足的问题，提高网络地址利用率。
    • 内网用户访问外网时，数据包会经过 NAT 转换。
    • 重点理解：隐藏内部网络结构，实现私网与公网通信。
  • PAT（端口地址转换）
    • 是 NAT 的一种特殊形式，也称为 NAPT 或端口复用。
    • 多个内网主机共享同一个公网 IP 地址访问互联网。
    • 通过不同的端口号区分不同主机的连接。
    • 重点理解：一个公网 IP 支持多个设备同时上网。
  • ACL（访问控制列表）
    • 作用：根据规则允许或拒绝网络流量通过。
    • 可基于源 IP、目标 IP、协议类型、端口号等进行控制。
    • 常用于流量过滤、访问限制和安全策略配置。
    • 重点理解：ACL 本质上是一组“允许/拒绝”规则。
  • DMZ（隔离区）
    • 位于内网与互联网之间的缓冲区域。
    • 通常部署 Web、FTP、DNS 等对外提供服务的服务器。
    • 即使 DMZ 服务器被攻击，也能降低对内部网络的影响。
    • 重点理解：DMZ 用于隔离公网与内网，提高安全性。
🤔 agent

Agent：检索增强生成（RAG）核心知识

  • Embedding：将自然语言转换为向量表示，便于语义检索。
  • Vector Search：通过向量相似度而非关键词匹配寻找相关知识。
  • Recall（召回）：从大量知识中快速找出候选结果。
  • Rerank（重排）：对召回结果进行二次排序，提高准确率。
  • Chunk：知识库中的最小检索单元，通常是一段文本。
  • TopK：保留相似度最高的 K 条结果进入后续处理流程。
  • Dedup：去除重复或高度相似内容，节省上下文窗口。
  • Embedding 与 Rerank 的区别：Embedding 负责召回，Rerank 负责精排。
  • RAG 检索流程：Question → Embedding → Vector Search → Recall → Dedup → Rerank → Prompt → LLM。
📌概率论

📚 第一章：随机事件与概率

  • 随机试验：结果不确定但可重复进行的试验。
  • 样本空间 Ω：随机试验所有可能结果组成的集合。
  • 样本点：样本空间中的一个基本结果。
  • 随机事件：样本空间的子集。
  • 必然事件：Ω，一定发生。
  • 不可能事件：∅，一定不发生。
  • 事件运算：并(∪)、交(∩)、差(-)、对立(Ā)。
  • 互斥事件：A∩B=∅，不能同时发生。
  • 对立事件：A∩B=∅ 且 A∪B=Ω。
  • 古典概率：在有限且等可能条件下， P(A)=有利情况数/总情况数。
  • 常用计数方法：加法原理、乘法原理、排列、组合。
  • 解题步骤：先求样本空间，再求有利情况数，最后利用古典概率公式计算。
