🔹 MCU 是什么

MCU 是 Microcontroller Unit，微控制器。 它可以理解为将一个小型计算机系统集成在一块芯片中。

一般 MCU 内部会集成：

  • CPU
  • 存储器
  • 输入输出接口
  • 定时器
  • 通信接口

MCU 常用于需要对具体设备进行控制的场景，例如：

  • 智能家居
  • 传感器设备
  • 工业控制
  • 汽车电子
  • 嵌入式设备
CPU 更强调计算和处理能力，
MCU 则更强调将计算、存储和控制功能集成起来，用于控制具体设备。

🔹 计算机的基本组成部分

计算机系统的硬件部分通常可以从五大组成部分来理解。

输入设备 ↓ 运算器 / 控制器 ↓ 存储器 ↓ 输出设备
  • 运算器：负责算术运算和逻辑运算。
  • 控制器：负责控制和协调计算机各部分工作。
  • 存储器：负责存放程序和数据。
  • 输入设备：将外部数据输入计算机。
  • 输出设备：将计算结果输出给用户。

CPU 的核心通常可以理解为：

CPU = 运算器 + 控制器

运算器负责“算什么”，控制器负责“什么时候算、执行什么指令以及如何协调各部分工作”。

🔹 指令系统

指令系统可以理解为：

CPU 能够识别并执行的全部指令的集合。

程序最终会被转换为机器能够执行的指令。 一条指令通常包含两个基本部分：

  • 操作码：告诉 CPU 要执行什么操作。
  • 地址码：告诉 CPU 操作的数据在哪里。

例如：

ADD R1, R2 ADD → 操作码 R1、R2 → 操作对象或地址信息

指令系统决定了 CPU 能够理解哪些机器指令， 不同处理器的指令系统可能不同。

🔹 CISC 与 RISC 的区别

CPU 的指令系统通常可以分为两种典型设计思想：

  • CISC：复杂指令集计算机
  • RISC：精简指令集计算机
对比 CISC RISC
指令数量 较多 较少
指令复杂度 较复杂 相对简单
指令长度 可能不同 通常较固定
执行方式 一条指令可能完成多个复杂操作 通过多个简单指令完成任务
典型代表 x86 ARM

可以简单理解为：

CISC：希望通过一条复杂指令完成更多事情。

RISC：将复杂任务拆成多个简单指令，提高执行效率和硬件设计的简洁性。

🔹 I/O 编址

I/O 编址主要讨论的是：

CPU 如何访问输入输出设备。

常见可以理解为两种思路：

统一编址

将 I/O 设备和内存统一放在同一个地址空间中。 CPU 通过访问地址，就可以访问内存或者 I/O 设备。

独立编址

I/O 设备拥有独立的地址空间， CPU 需要使用专门的 I/O 指令访问设备。

统一编址： 内存地址空间 + I/O 地址空间 独立编址： 内存地址空间 I/O 独立地址空间

🔹 直接寻址与间接寻址

寻址方式主要解决的问题是：

指令如何找到需要操作的数据。

直接寻址

指令中直接给出操作数所在的地址。

指令 ↓ 直接得到数据地址 ↓ 访问数据

间接寻址

指令中给出的地址并不是最终的数据地址， 而是一个存放真实地址的位置。

指令 ↓ 找到地址 A ↓ A 中保存真实数据地址 ↓ 找到数据

简单理解：

直接寻址：直接告诉你数据在哪里。

间接寻址：先告诉你“数据地址在哪里存着”，再去找真正的数据。

🔹 内存扩展和什么有关

扩展内存主要涉及：

  • 地址线数量
  • 数据线数量
  • 存储芯片容量
  • 芯片之间的连接方式

可以从两个方向理解内存扩展：

位扩展

增加数据位数，让一次能够存储或传输更多位的数据。

字扩展

增加可寻址的存储单元数量，从而扩大总存储容量。

地址线主要决定能够访问多少个存储单元。
数据线主要与一次能够传输多少位数据有关。

🔹 冯·诺依曼体系结构

冯·诺依曼体系结构是现代计算机最重要的基础结构之一。 它的核心特点包括：

  • 采用存储程序思想
  • 程序和数据存放在存储器中
  • 程序和数据通常共享同一存储空间
  • CPU 按照指令顺序进行取指和执行
存储器 │ ├── 程序 └── 数据 CPU 从同一个存储空间中获取指令和数据

这种结构的优点是设计相对统一， 但程序和数据共享通道也可能形成访问瓶颈。

🔹 哈佛体系结构

哈佛体系结构的一个核心特点是：

指令存储器和数据存储器分开。
指令存储器 ↓ CPU ↑ 数据存储器

因为指令和数据使用不同的存储空间和通路， 所以理论上可以同时进行取指和数据访问。

因此可以简单记忆：

结构 特点
冯·诺依曼结构 程序和数据共享存储空间
哈佛结构 程序和数据分别使用不同存储空间

🔹 ARM 公司与 ARM 架构

ARM 是一家专注于处理器架构设计和授权的重要公司。 ARM 本身并不是主要通过生产所有处理器芯片来销售， 而是设计处理器架构和相关 IP，再授权给其他厂商。

ARM 架构通常采用 RISC 的设计思想， 具有功耗较低、效率较高等特点。

因此 ARM 架构广泛应用于：

  • 手机
  • 平板
  • 嵌入式设备
  • 物联网设备
  • 部分服务器
  • 智能终端
ARM 公司可以理解为主要设计“处理器架构和技术方案”， 然后通过授权让不同厂商基于 ARM 架构生产自己的芯片。
