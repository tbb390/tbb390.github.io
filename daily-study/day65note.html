agent

  • 小u同学配api秘钥：左上角添加模型，账号，key，模型供应商选择对应的，如果没有就选自定义了。
  • 在小u同学中添加skill的方法：左侧选中mcp&skills，添加我的，导入，SKILL.md要大写的,添加后点打开，不用的技能关闭
  • 触发和调用：1，描述任务目标让助手自动匹配2，直接/skillname,调用3，助手主动调用

  • mcp可以把外部能力接进来的一系列协议，连接数据，应用，服务能力api
  • 做题把题目存成md，根据题目把接口以mcp的形式封装起来，形成mcp服务
  • 把给出的存在本地md中，复制json时候注意本地路径（属性），第二行是mcp自定义名字，command是语言，args是本地路径,env配置。添加好后就可以给小u说调用mcp来处理什么
  • 知识库，先下载向量插件（根据向量相似度进行检索），使用本地，别选全局，可以把题目存在知识库，文档过长的话商店下载pdf转换插件。语义搜索更精准，不会有上下文的污染。
  • ctrl+alt+p呼出终端下载 sudo apt update ,sudo spt install python3，也可以商店下载ide
  • skill是告诉小u应该怎么完成用什么完成，mcp是给工具接口，Skill 规定查询与保存流程 告诉agent使用教程，MCP 提供 grade_query 的调用接口让agent能操作。
