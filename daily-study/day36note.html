🤖 Agent比赛模拟题训练

智能体应用开发实践赛知识点整理。

1. 大模型适配与优化：PEFT

  • 理解参数高效微调（PEFT）的基本思想：不修改全部模型参数，只训练少量参数，使大模型适应具体业务场景。
  • 常见方法包括 LoRA、Adapter、Prefix Tuning。
  • 相比全量微调，PEFT 可以降低显存需求和训练成本，更适合业务场景中的模型定制。

PEFT 与全量微调区别：

  • 全量微调：训练全部参数，效果较好，但资源消耗较高。
  • PEFT：训练少量参数，成本更低，适合企业应用快速适配。

2. RAG知识增强

  • RAG（Retrieval Augmented Generation）的核心思想是不修改模型参数，通过外部知识增强模型回答能力。
  • 基本流程： 知识库检索 → 获取相关资料 → Prompt增强 → LLM生成答案。
  • 相比重新训练模型，RAG更新知识更加方便，适合企业知识库问答场景。

理解： RAG让模型“查看资料”，微调让模型“学习新的能力和习惯”。

3. Agent智能体核心流程

  • Agent不仅负责生成回答，还需要完成任务规划、工具调用和结果反馈。
  • 核心流程： 用户目标 → LLM推理规划 → 工具调用 → 环境执行 → 结果反馈 → 继续决策。
  • LLM主要负责理解需求、拆解任务、选择工具以及生成工具参数。

4. Agent工具调用机制

  • 理解 Tool Calling 的基本流程： 用户请求 → LLM分析 → 选择工具 → 生成参数 → 执行工具 → 返回结果。
  • 工具调用失败时，需要先分析错误原因，再判断是否重试、修改参数或更换工具。
  • 不能无限重试，也不能默认任务已经成功。

5. LLM生成控制参数

  • Top-k： 限制候选 Token 数量，例如 Top-k=10 表示每次只从概率最高的10个候选中选择。
  • Top-p： 根据累计概率动态选择候选范围，候选数量会随着概率分布变化。
  • 两者都会影响模型生成结果的随机性和多样性。

6. AI计算硬件基础

  • CPU： 通用处理器，适合操作系统、应用程序等通用计算任务。
  • GPU： 擅长大规模并行计算，主要应用于深度学习训练和矩阵计算。
  • NPU： 针对神经网络计算设计，用于 AI 推理加速。

理解： CPU负责通用计算，GPU负责并行计算，NPU负责AI专用计算。

7. Linux权限管理与数据库基础

  • Linux权限模型包括 User、Group、Others 三类对象。
  • 权限主要包括 r（读取）、w（写入）、x（执行）。
  • 了解 umask 对新创建文件默认权限的影响。
  • 复习 NoSQL 数据库类型： Redis（键值型）、MongoDB（文档型）、HBase（列族型）。

8. 软件工程相关知识

  • 理解 ABI（Application Binary Interface）与 API 的区别。
  • API 更关注源码层面的接口调用，ABI关注编译后程序之间的兼容。
  • 了解回归测试在系统升级、版本发布中的作用。
  • 故障记录能够帮助快速复现问题、分析原因并避免重复故障。

🧠 深度学习：神经网络与模型诊断

继续学习深度学习模型训练过程，重点理解神经网络、过拟合以及模型优化方法。

  • 理解神经网络是由多个基础模型组合而成，通过多层结构完成特征转换，解决传统线性模型无法处理的问题。
  • 模型训练过程中，需要结合训练误差和测试误差判断模型状态。
  • 如果训练误差较大，可能是模型能力不足或者优化过程存在问题。
  • 如果训练误差较小但测试误差较大，说明模型出现过拟合。

模型优化方向：

  • 增加训练数据，提高模型学习范围。
  • 使用数据增强改善数据规模。
  • 通过正则化、Dropout、Early Stopping等方式提升泛化能力。

模型评估方法

  • 训练集用于学习模型参数。
  • 验证集用于调整模型和选择方案。
  • 测试集用于最终评价模型效果。
  • 避免反复根据测试结果修改模型，防止测试集过拟合。

同时理解了数据分布不匹配问题： 如果训练数据和实际应用环境差异较大，即使不断调整模型参数，也可能无法获得理想效果。
