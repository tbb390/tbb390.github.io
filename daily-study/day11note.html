刷题记录 · 鹅鸭杀（二刷）

Problem C · 区间贪心 · 排序 + 小根堆

一、题目回顾

本题来源于竞赛 Problem C（鹅鸭杀）。 给定若干区间，每次选择一个整数点，使得：

  • 每个区间最多使用一次
  • 每次选择的点必须落在该区间内
  • 所选点互不相同

目标是：最大化被选中的区间数量。

二、一刷的问题

  • 被题目背景（鹅 / 鸭 / 人数）干扰，没有第一时间抽象模型
  • 知道要贪心，但不确定贪心的依据
  • 小根堆只是“照着写”，不清楚其必要性

三、二刷核心抽象

问题本质：

动态区间选择问题 —— 每次从所有 l ≤ 当前点 ≤ r 的区间中， 选择一个区间匹配当前点，使总匹配数最大。

四、贪心策略说明

为什么选右端点最小的区间？

  • 右端点小的区间更容易“过期”
  • 如果现在不用，后面可能再也用不上
  • 保留右端点大的区间，能给后续留下更多选择

这是典型的「区间调度 / 最早结束时间优先」思想。

五、算法流程

  1. 按区间左端点排序
  2. 维护一个按右端点排序的小根堆
  3. 当前点从 1 开始递增
  4. 将所有 l ≤ 当前点 的区间加入堆
  5. 弹出右端点最小且仍合法的区间

六、二刷 AC 代码


#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i].first >> a[i].second;
    }

    sort(a.begin(), a.end());

    priority_queue, vector>, greater>> pq;

    int cnt = 0, idx = 0;
    vector ans;

    while (true) {
        while (idx < n && a[idx].first <= cnt + 1) {
            pq.push({a[idx].second, idx});
            idx++;
        }

        while (!pq.empty() && pq.top()[0] < cnt + 1) {
            pq.pop();
        }

        if (pq.empty()) break;

        auto [r, id] = pq.top();
        pq.pop();

        cnt++;
        ans.push_back(id + 1);
    }

    cout << cnt << '\n';
    for (int i = 0; i < ans.size(); i++) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';

    return 0;
}

七、二刷总结

本题本质是动态区间贪心问题。 二刷的关键不在代码，而在于：

  • 能否快速抽象为区间模型
  • 是否明确“右端点最小”贪心的必要性
  • 是否真正理解小根堆维护的含义
