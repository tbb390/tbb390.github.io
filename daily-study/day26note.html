📌 教资科二

📖 第三章：中学教学——教学原则与教学方法

教学原则概述

教学原则是根据教学规律制定的指导教学工作的基本要求，是教师开展教学活动必须遵循的基本准则。本节是科目二高频考点，选择题、辨析题、简答题、材料分析题均可能出现。

八大教学原则（高频简答+材料分析）

记忆口诀： 冯巩找阴凉，寻思理直发

  • 冯：巩固性原则
  • 巩：因材施教原则
  • 找：循序渐进原则
  • 阴：思想性与科学性统一原则
  • 凉：量力性原则
  • 寻：理论联系实际原则
  • 思：启发性原则
  • 理直发：理论联系实际、直观性、启发性（辅助记忆）

    • 另一记忆顺序： 直启巩循，理思量因

    即： 直观性 → 启发性 → 巩固性 → 循序渐进 → 理论联系实际 → 思想性与科学性统一 → 量力性 → 因材施教。

    1. 直观性原则

    通过学生感官直接感知具体事物或表象，帮助学生形成清晰认识。

  • 形式：实物直观、模象直观、言语直观。

    • 贯彻要求口诀： 选择语言不滥用

  • 选择：正确选择直观教具。
  • 语言：直观与教师讲解结合，重视语言直观。
  • 不滥用：避免直观材料使用不当。

    • 2. 启发性原则

    调动学生学习主动性，引导学生独立思考、积极探索。

    贯彻要求口诀： 牧民发问

  • 牧：明确教学目的。
  • 民：发扬教学民主。
  • 发：启发学生独立思考。
  • 问：培养学生发现问题和解决问题能力。

    • 3. 巩固性原则

    要求学生在理解基础上牢固掌握知识，并能够灵活运用。

  • 理解基础上巩固。
  • 组织复习巩固。
  • 通过实践运用巩固。

    • 4. 循序渐进原则

    按照学科逻辑和学生认知规律进行教学，由浅入深、由易到难。

  • 遵循教材系统性。
  • 抓住教学重点。
  • 合理安排教学顺序。

    • 5. 理论联系实际原则

    把理论知识与现实生活、社会实践结合，使学生学以致用。

  • 联系实际理解书本知识。
  • 培养学生运用知识能力。
  • 结合实际补充乡土教材。

    • 6. 思想性与科学性统一原则

    教学既要保证知识科学准确，又要结合教学内容进行思想品德教育，实现教书育人。

    7. 量力性原则

    教学内容、方法和进度要符合学生身心发展水平，难度适合学生接受能力。

  • 核心：符合学生最近发展区。

    • 8. 因材施教原则

    根据学生个体差异采取不同教学措施，使每个学生得到发展。

  • 了解学生特点。
  • 坚持统一要求。
  • 发现学生优势，创造发展条件。

    • 中小学常用教学方法（分类记忆）

    分类口诀： 讲讨练实参，蒋导演活时习惯谈论恋情

    一、语言传递为主

  • 讲授法：教师系统讲解知识。
  • 谈话法：教师提问，学生回答。
  • 讨论法：学生围绕问题交流讨论。
  • 读书指导法：教师指导学生阅读教材。

    • 二、直观感知为主

  • 演示法：教师展示实物、模型、实验等。
  • 参观法：组织学生到实际场所观察学习。

    • 三、实际训练为主

  • 练习法：通过反复练习形成技能。
  • 实验法：学生通过实验操作获得知识。
  • 实习作业法：通过实际任务培养实践能力。

    • 四、情感陶冶为主

  • 欣赏教学法：通过体验美进行教育。
  • 情境教学法：创设情境，引发学生情感体验。

    • 教学方法选择依据

  • 教学目的和任务。
  • 课程性质和教材特点。
  • 学生年龄特点和学习水平。
  • 教学时间、设备条件。
  • 教师自身能力水平。

    • 本节核心总结

    本节重点掌握八大教学原则口诀“冯巩找阴凉，寻思理直发”以及每个原则的贯彻要求，材料分析题需要根据教师行为判断体现的教学原则；教学方法重点掌握四大分类及各方法特点，通过口诀快速区分，是中学教学章节中必考内容。

    📌 深度学习（李宏毅课程）

    🧠 前三讲核心框架：Regression、Gradient Descent 与 Backpropagation

    整体理解：深度学习训练流程的建立

    李宏毅老师前三讲主要围绕深度学习模型训练的底层流程展开，从最简单的回归问题开始，逐步引入优化算法和梯度计算方法，建立完整的机器学习训练框架。

  • Regression：介绍如何将实际问题转化为机器学习问题，即通过建立模型函数，根据输入预测输出。
  • Gradient Descent：解决如何优化模型参数，使模型预测误差不断降低。
  • Backpropagation：解决深层神经网络参数数量巨大时，如何高效计算梯度的问题。

    • 三者共同构成深度学习训练的核心流程： 模型建立 → Loss计算 → 梯度求解 → 参数更新。

    第一讲：Regression（回归）——机器学习问题建模流程

    一、Regression 的基本概念

    回归任务的目标是学习一个函数，使输入特征 x 能够映射到连续数值输出 y。

    例如宝可梦 CP 值预测任务：

  • 输入：宝可梦当前属性，如 CP、HP、重量等。
  • 输出：进化后的 CP 值。

    • 该任务属于监督学习，因为训练数据中包含输入与对应标签，通过大量样本学习输入与输出之间的映射关系。

    二、Model：定义函数空间

    机器学习首先需要选择模型，也就是确定函数形式。

    例如线性回归模型：

    y = b + wx

  • w 表示输入特征对于输出结果的影响程度。
  • b 表示整体偏移量。

    • 调整不同的 w 和 b，可以得到不同的函数，因此模型本质上定义了一组可能的函数集合，训练过程就是从这些函数中寻找最符合数据规律的函数。

    随着任务复杂度增加，可以引入更多特征或更复杂模型结构，提高模型表达能力，但同时也增加过拟合风险。

    三、Loss Function：衡量模型效果

    模型输出预测结果后，需要通过评价指标判断预测效果，因此引入损失函数。

    回归任务常采用均方误差（MSE）：

    Loss = Σ(预测值 - 真实值)²

  • Loss 越小，说明模型预测结果与真实值越接近。
  • 训练过程的目标就是寻找使 Loss 最小的参数组合。

    • 可以将 Loss 看作关于模型参数的函数，不同参数组合对应不同 Loss 值，优化过程就是寻找 Loss 函数的最低点。

    四、Optimization：梯度下降寻找最优参数

    由于参数空间通常很大，无法直接枚举所有参数组合，因此需要使用优化算法。

    梯度下降的核心思想是：

    根据当前参数位置计算 Loss 变化最快的方向，并沿相反方向更新参数。

    更新公式：

    θ = θ - η∇L(θ)

  • θ：模型参数。
  • η：学习率。
  • ∇L：Loss 对参数的梯度。

    • 通过不断迭代，使模型参数逐渐接近最优解。

    五、过拟合与正则化

    当模型复杂度不断提高时，模型可能不仅学习数据中的规律，还会学习训练数据中的噪声，从而导致泛化能力下降。

    这种现象称为过拟合（Overfitting）。

  • 训练集表现优秀。
  • 测试集效果下降。

    • 解决过拟合的方法之一是正则化（Regularization）。

    核心思想是在 Loss 中增加模型复杂度惩罚项：

    Loss = 原误差 + λΣw²

  • 限制参数过大，使模型更加平滑。
  • 降低模型对训练数据噪声的敏感程度。

    • 其中 λ 控制正则化强度：

  • λ 较小：约束不足，容易过拟合。
  • λ 较大：限制过强，可能导致欠拟合。

    • 第二讲：Gradient Descent（梯度下降）——模型优化方法

    一、梯度下降基本原理

    梯度表示函数值增长最快的方向，因此如果希望降低 Loss，需要沿梯度相反方向更新参数。

    梯度下降公式：

    θ(new)=θ(old)-η∇L(θ)

    其中学习率决定每次更新幅度，是影响训练效果的重要超参数。

    二、学习率的影响

  • 学习率过大： 更新幅度超过最优点，导致 Loss 震荡甚至无法收敛。
  • 学习率过小： 参数更新缓慢，训练效率降低。

    • 因此实际训练过程中，需要选择合适学习率，使模型稳定快速收敛。

    三、Adagrad 自适应学习率

    传统梯度下降中所有参数共享同一个学习率，而 Adagrad 根据不同参数历史梯度大小自动调整学习速度。

  • 梯度较大的方向：降低学习率，避免更新过快。
  • 梯度较小的方向：提高学习率，加快优化。

    • 其核心思想是让不同参数拥有不同的更新步长，提高训练效率。

    四、Feature Scaling（特征缩放）

    当不同特征的数值范围差异较大时，会影响 Loss 函数的形状，使梯度下降过程出现震荡。

    例如一个特征范围为 0-1000，另一个范围为 0-1，会导致模型优化偏向数值范围大的特征。

    通过标准化或归一化处理，使不同特征处于相近尺度，可以提升梯度下降效率。

    第三讲：Backpropagation（反向传播）——深度学习训练核心算法

    一、反向传播解决的问题

    梯度下降需要计算 Loss 对每一个参数的梯度。

    但深度神经网络通常包含大量参数，如果逐个计算参数变化对 Loss 的影响，计算成本极高。

    反向传播利用链式法则，高效计算网络中所有参数的梯度，使大规模神经网络训练成为可能。

    二、链式法则与梯度计算

    神经网络本质上是多层复合函数：

    输入 → 隐藏层 → 输出层 → Loss

    因此某个参数对 Loss 的影响，需要经过多层函数传递。

    链式法则将复杂梯度拆分为多个局部梯度的乘积，实现逐层计算。

    三、Forward Pass 与 Backward Pass

    前向传播：

  • 计算模型输出。
  • 记录各层输入和中间结果，为梯度计算提供数据。

    • 反向传播：

  • 从输出层开始计算误差信号。
  • 利用链式法则逐层向前传递梯度。

    • 最终得到每个参数对应的梯度，并用于梯度下降更新。

    前三讲总结

    前三讲建立了深度学习训练的完整理论基础：

  • Regression 定义如何通过模型表示问题。
  • Loss Function 衡量模型预测误差。
  • Gradient Descent 根据梯度优化模型参数。
  • Backpropagation 高效计算梯度，使深度网络训练成为可能。

    • 后续 CNN、RNN、Transformer 等模型主要变化在于 Model 部分，即如何设计更强的函数结构，而训练过程仍然遵循：

    模型构建 → Loss计算 → 反向传播 → 梯度下降更新参数。
