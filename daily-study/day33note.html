🤖 Agent比赛学习复盘

今天主要继续推进 Agent 比赛相关内容，对智能体系统的整体设计思路进行了复习和理解。

从实际应用角度来看，一个 Agent 系统并不是简单调用大模型，而是需要围绕任务目标搭建完整执行链路，包括用户需求理解、任务拆解、工具调用、上下文管理以及结果生成。

重点理解了 Agent 与普通 Chatbot 的区别： 普通对话机器人主要依赖模型本身进行回答，而 Agent 更强调“规划 + 执行”的能力，可以根据目标主动选择步骤，并通过工具获取外部信息完成任务。

同时结合之前 RAG 项目的经验，对知识增强方向进行了复盘： RAG 的核心流程包括文档解析、文本切分、Embedding 向量化、向量检索、召回结果融合以及大模型生成回答。 其中检索质量和上下文构建会直接影响最终回答效果。

今天的重点不是单纯记忆框架，而是进一步理解 Agent 系统背后的工程逻辑： 模型负责推理，大量外围模块负责提供信息、执行动作以及控制流程，最终形成一个完整智能应用。

🧠 深度学习复盘 —— 逻辑回归与生成模型

今天学习了李宏毅老师深度学习课程中的逻辑回归、判别式模型与生成式模型部分。

核心理解： 机器学习模型实际上是在选择一种“归纳偏置”，即模型是否愿意对未知情况进行假设。

判别式模型（Discriminative Model）更加关注： 给定输入 x，直接学习分类结果，例如学习 P(C|x)。 它更加依赖已有数据，不主动假设数据背后的产生规律，因此在数据量充足时通常表现更好。

生成式模型（Generative Model）则尝试学习数据产生过程： 通过估计 P(x|C) 和 P(C)，再利用概率关系进行分类。 它会加入一定假设，相当于对未知情况进行“脑补”。

通过 toy example 理解了为什么生成模型有时候反而有效： 当训练数据较少、数据存在噪声或者标签不完全可靠时，合理的先验假设可以帮助模型弥补数据不足。

随后学习了多分类情况下的 Softmax： 通过将多个类别对应的 score 转换为概率分布，使模型能够输出不同类别属于当前输入的概率。 Softmax 的核心作用是： 将不同类别的竞争关系转化为概率形式，同时通过指数函数强化较大的预测结果。

今天最大的收获： 模型性能不仅取决于算法复杂度，也取决于模型对于世界规律的假设是否适合当前任务。

📚 教资科二复盘 —— 学习心理部分

今天完成了教育心理学第四章后半部分内容整理，重点掌握学习理论、学习动机以及学习策略相关简答题。

【有意义学习】 核心是把新知识与已有认知结构建立内在、非字面的联系。 实现条件包括： 学习材料具有逻辑意义； 学生已有相关知识基础； 学生具有主动建立联系的学习心向。

【学习动机培养与激发】 培养方面： 结合学生需要促进动机产生； 加强立志教育和成就动机训练； 帮助学生建立正确自我概念，提高自我效能； 培养努力导致成功的归因方式。

激发方面： 根据任务难度控制动机水平； 合理使用奖励和惩罚； 采用启发式教学； 正确指导学生进行学习结果归因。

【学习策略】 认知策略包括： 复述策略——重复强化信息； 精加工策略——建立新旧知识联系； 组织策略——形成知识结构。

元认知策略包括： 计划、监控、调节。 作用是帮助学生提高学习效率，实现自主学习。

同时复习了桑代克学习规律： 准备律、效果律、练习律； 观察学习过程： 注意、保持、再现、动机； 学习迁移类型以及操作技能形成阶段： 定向、模仿、整合、熟练。
