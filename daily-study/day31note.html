📚 教资科二：教育知识与能力

1. 有效教学的基本要求

  • 面向全体学生： 教学应关注学生整体发展，保证所有学生都能够参与学习过程。
  • 关注学生差异： 根据学生基础、能力和特点进行针对性教学。
  • 明确教学目标： 教学活动应围绕目标展开，提高教学效率。
  • 促进学生主动学习： 重视学生主体地位，引导学生积极参与。

2. 循序渐进教学原则

含义： 教学要遵循学生认识发展规律和知识内在逻辑， 按照由浅入深、由易到难、由简到繁的顺序进行。

贯彻要求（系统认识、连贯、矛盾）：

  • 系统认识： 按照教材体系组织教学，使学生形成完整知识结构。
  • 连贯教学： 注意新旧知识之间的联系，保证学习过程连续。
  • 处理矛盾： 根据学生实际水平调整教学难度，解决教学要求与学生能力之间的矛盾。

3. 课外辅导的要求

  • 补充教学内容： 针对课堂学习不足进行补充和强化。
  • 解决实际问题： 根据学生学习情况给予具体指导。
  • 指导学习方法： 启发学生掌握正确学习方法，提高自主学习能力。

4. 因材施教原则贯彻要求

  • 统一要求： 面向全体学生，保证基本教学目标实现。
  • 了解差异： 了解学生知识基础、能力水平和个性特点。
  • 发现兴趣： 根据学生兴趣特长进行培养，促进个性发展。

🤖 AI 模型部署与异构计算原理

大模型部署不能简单认为“模型越大越好”， 也不能通过单一 GPU 参数或 TOPS 指标决定方案。

实际部署需要综合考虑：

  • 模型结构
  • 参数规模
  • 权重精度
  • 上下文长度
  • 并发规模
  • 推理框架
  • 硬件架构
  • 目标性能指标

模型部署三层结构：

  • 模型文件： 保存模型权重、结构配置和相关参数。
  • 推理引擎： 加载模型并调用 CPU、GPU 或 AI 加速器完成计算。
  • 服务接口： 通过 HTTP 等方式向业务系统提供模型能力。

例如 vLLM 可以提供 OpenAI 兼容接口， 这里的兼容主要表示接口格式一致， 不代表模型能力和 OpenAI 模型完全相同。

大模型显存组成：

  • 模型权重： 主要受到参数规模和精度影响。
  • KV Cache： 主要受到上下文长度和并发数量影响。

同一个模型在单用户短上下文和多用户长上下文场景下， 对显存需求可能存在巨大差异。

模型量化：

  • W4： 权重使用 4bit 存储。
  • FP8： 使用 8bit 浮点计算。

量化效果需要结合模型结构、硬件支持和推理框架优化能力， 不能只根据量化位数判断性能。

MoE 混合专家模型：

  • 总参数量： 影响模型文件大小和存储需求。
  • 激活参数量： 影响实际 Token 推理计算量。

因此 MoE 模型不能简单通过总参数规模判断部署难度。

硬件选型流程：

确定模型 → 确定量化方案 → 确定上下文长度 → 确定并发规模 → 确定延迟和吞吐要求 → 选择硬件 → 实际测试

主要测试指标：

  • 首 Token 延迟
  • Token 生成速度
  • 整体吞吐量
  • 显存占用
  • 长时间运行稳定性
