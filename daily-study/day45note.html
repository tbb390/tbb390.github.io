Agent 比赛模拟与 UOS / Linux

今天继续进行 Agent 比赛相关内容的学习和模拟，主要结合比赛题目复习 Linux、UOS、网络运维以及机器学习相关知识，同时继续熟悉比赛中的实际 Shell 操作流程。

Linux 和 UOS 部分主要涉及寄存器、磁盘、文件权限、根分区空间、服务状态、中断、信号以及跨平台兼容等内容。

  • 寄存器位于 CPU 内部，访问速度快，但容量较小。
  • 固态硬盘相比机械硬盘具有更快的读写速度。
  • umask 用于影响新建文件和目录的默认权限。
  • 普通文本文件常见权限为 644，目录常见权限为 755。
  • 根分区空间占满后可能导致日志无法写入、临时文件无法创建以及部分程序运行异常。
  • 磁盘空间异常增长时，需要检查大文件、日志文件、临时文件以及已经删除但仍被进程占用的文件。
  • systemctl status 可以查看服务运行状态。
  • SIGKILL 用于强制终止进程，不能被捕获和忽略；SIGTERM 更适合正常终止进程。
  • 硬件中断发生后，CPU 会保存当前状态并进入对应的中断处理程序。

跨平台部分继续关注 CPU 架构、驱动、运行库、ABI 和软件依赖等兼容问题。软件能否迁移到不同平台运行，需要同时考虑硬件架构和底层运行环境。

比赛实际操作

实操部分继续熟悉 Linux 的目录和文件操作，并按照比赛要求进行目录、文件和数据文件的创建与检查。

  • whoami：查看当前登录用户。
  • pwd：查看当前所在目录。
  • mkdir：创建目录。
  • cd：进入指定目录，cd .. 返回上一级目录。
  • ls：查看目录中的文件和文件夹。
  • echo：输出文本内容。
  • >：创建或覆盖写入文件。
  • >>：在原有内容后追加写入。
  • cat：查看文件内容。
  • $(命令)：获取命令执行结果后继续使用。

同时继续熟悉 CSV 文件的基本格式和系统信息查看命令，包括使用 uname -m 查看 CPU 架构、uname -r 查看内核版本、date 查看系统时间、df -h / 查看根分区磁盘使用情况、free -h 查看内存以及 ip addr 查看网络接口和 IP 地址。

教资科三：计算机网络

今天主要根据知识导图复习计算机网络概述、网络体系结构以及 Internet 协议与应用相关知识。

计算机网络概述部分涉及计算机网络的定义、通信设备和线路、资源共享以及常见的传输介质。有线传输主要包括双绞线、同轴电缆和光纤，无线传输则主要通过电磁波等方式进行。

网络设备部分继续区分不同设备的作用和层次。网卡负责设备接入网络，中继器和集线器主要处理物理层信号，交换机主要处理数据链路层数据，路由器负责网络层的 IP 地址识别和路径选择，网关则用于不同网络或协议之间的连接。

网络组成和拓扑结构部分复习了局域网、城域网和广域网，以及总线型、环型、星型、树型和网型等常见网络拓扑结构。

网络体系结构部分重点学习网络协议和分层设计。网络协议主要包括语法、语义和时序，分层设计通过不同层之间的接口和协议实现协作。

OSI 参考模型继续按照七层进行梳理：

  • 应用层：面向用户和应用程序。
  • 表示层：负责数据表示和编码。
  • 会话层：负责建立、维护和终止会话。
  • 传输层：负责端到端通信。
  • 网络层：负责寻址和路由。
  • 数据链路层：负责节点之间的数据传输。
  • 物理层：负责比特流和物理传输。

同时复习 TCP/IP 参考模型，主要包括应用层、传输层、网络层和网络接口层。

Internet 协议部分继续学习 IPv4、IPv6、IP 地址组成、子网技术以及 TCP 和 UDP 的基本区别。IPv4 使用 32 位地址，IPv6 使用 128 位地址。TCP 是面向连接的可靠传输协议，UDP 是无连接的传输协议。

应用层协议部分继续梳理 DNS、HTTP、FTP、SMTP、POP3、TELNET 和 DHCP 等常见协议及其基本用途。
