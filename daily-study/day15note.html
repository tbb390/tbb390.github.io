📖agent
  • Function Calling / Tools：执行层机制，负责生成结构化工具调用请求。
  • Tool Schema：工具说明书，包含 name、description、parameters。
  • Tool Calling：Function Calling 的通用名称，本质一致。
  • Agent执行流程： 用户 → Agent → Tool → Tool Result → LLM → 用户
  • ReAct：Reason + Act，通过「思考→行动→观察」循环完成任务。
  • RAG：Retrieval Augmented Generation（检索增强生成）。
  • 为什么需要RAG：解决知识过时、幻觉问题，让回答基于真实知识库。
  • Embedding：将文本转换为向量表示。
  • 向量数据库：存储Embedding，实现语义检索。
  • 检索增强生成流程： 问题 → Embedding → 向量检索 → 知识召回 → LLM生成答案
  • MCP：Model Context Protocol，工具标准化接入协议。
  • MCP作用：统一工具接入方式，降低系统与工具耦合。
  • Skill：策略文档（Prompt），告诉模型如何思考、如何使用工具。
  • Skill与MCP区别： MCP负责接入能力； Skill负责使用能力。
  • 三层结构： Skill（策略层） → MCP（接入层） → Function Calling / Tools（执行层）
  • 三句话记忆： Function Calling 是机制； MCP 是接入协议； Skill 是策略文档。
  • 结合Ragent理解Agent： Agent = LLM + Prompt + Tool + RAG + MCP。

    🤔计网

    计算机网络笔记：静态路由、VLAN与三层交换机

    • 静态路由
      • 管理员手动配置路由表，适用于小型网络。
      • 优点：简单、开销小。
      • 缺点：无法自动适应网络拓扑或流量变化。
      • 错误配置可能导致网络故障或路由环路。
    • 默认路由
      • 路由条目：0.0.0.0/0
      • 当路由表中没有匹配路由时使用
      • 通常用于访问外网或未知网络
    • 特定主机路由
      • 配置/32路由，如192.168.2.1/32
      • 遵循最长前缀匹配原则，优先级高于网络路由和默认路由
    • 路由环路
      • 数据包在多个路由器之间循环转发
      • 常见原因：静态路由配置错误
      • 防止永久循环：TTL字段每经过路由器减1，TTL=0时丢弃数据包
    • VLAN作用
      • 划分广播域，实现网络隔离
      • 减少广播流量，提高网络效率
      • 同一VLAN内主机可直接二层通信，不同VLAN默认不能通信
    • SVI（Switch Virtual Interface / VLANIF）
      • 三层交换机创建VLAN后自动生成逻辑三层接口
      • 配置IP地址后产生直连路由
      • 通常作为该VLAN主机的默认网关
      • 用于实现不同VLAN之间通信
    • 三层交换机
      • 同时具备交换机和路由器功能
      • 负责不同VLAN之间的数据转发
      • 性能通常高于传统路由器
    • 三层交换机 VS 路由器
      • 共同点：都能实现不同网段之间的路由转发。
      • 三层交换机主要用于局域网内部VLAN间通信。
      • 路由器主要用于连接不同网络或连接互联网。
      • 三层交换机转发速度快，适合园区网和企业内网。
      • 路由器功能更丰富，支持NAT、ACL、VPN等高级功能。
      • 三层交换机通过SVI实现VLAN间路由。
      • 路由器通过物理接口进行路由转发。
