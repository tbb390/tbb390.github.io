agent 全景

  • 两条链路：导入和查询。
  • 导入链路：将文件导入到知识库中：entrynode，调用mineru转化为md文件，
    进行文档切分，提取各标题，识别设备名，生成向量。结果的文件和图片处理后存在minio中,
    向量存在milvus，对话历史和元数据存在MongoDB
  • 查询链路：用户提问，系统结合对话确认设备名，
    并行进行向量检索、HyDE 检索和 Web 搜索，
    汇总答案后进行RRF
    rerank后给llm结合检索结果生成答案
  • langgraph负责编排流程，节点执行时，它要决定先后顺序。state在节点间传递数据。当分支或者并行时，负责调度
    mineru负责解析文档和转化格式
    Qwen-VL 理解图片并生成描述
    BGE-M3负责向量化,把文本转换成向量
    milvus保存这些产生的向量，并且按相似度检索相关的切片
    MCP 按查询链路接入 Web 搜索
    RRF 合并多路结果，Rerank 精排候选结果。
    Qwen LLM 识别设备名、组织答案
