    agent
    • Agent（1h）
      • Function Calling：大模型根据用户需求选择并调用预定义函数，而不是直接生成最终答案。
      • Tool：供 Agent 使用的外部能力，如搜索、数据库查询、代码执行等。
      • Tool Calling 流程：
        • 用户提出需求
        • LLM 判断是否需要工具
        • 生成工具调用参数
        • 执行工具并获取结果
        • LLM结合结果生成最终回复
      • Tool Schema：工具的接口描述，定义工具名称、功能、参数类型及参数约束。
      • 作用：帮助模型准确理解工具用途并生成正确的调用参数。
      • Agent 本质：LLM + Memory + Planning + Tool Use。
    📌计算机网络
    • MAC地址
      • 网卡唯一标识，叫硬件地址，又称物理地址
      • 交换机根据MAC地址转发数据
    • 交换机转发
      • 学习MAC地址与端口对应关系
      • 根据MAC地址表进行转发
    • 广播域
      • 广播报文能够到达的范围
      • 同一广播域内所有设备都能收到广播
    • 冲突域
      • 可能发生数据碰撞的范围
      • 交换机每个端口是独立冲突域
    • VLAN作用
      • 隔离广播域
      • 提高安全性
      • 便于管理
      • 减少广播流量
    • VLAN划分
      • 基于端口划分（最常用）
      • 基于MAC地址划分
      • 基于IP地址划分
    • 总结
      • 交换机解决冲突域问题
      • VLAN解决广播域问题
      • 一个VLAN就是一个广播域
      • VLAN本质是将一个大广播域划分为多个小广播域
    🤔 概率与统计
    • 第一章基础概念
      • 随机试验：在相同条件下可重复进行，结果事先不能确定的试验。
      • 样本空间 Ω：随机试验所有可能结果组成的集合。
      • 随机事件：样本空间的子集，分为必然事件、不可能事件和随机事件。
      • 事件关系：包含、相等、互斥、对立等关系。
      • 事件运算：并（A∪B）、交（A∩B）、差（A-B）、补（Ā）。
      • 概率定义：描述事件发生可能性大小的数值，取值范围为[0,1]。
