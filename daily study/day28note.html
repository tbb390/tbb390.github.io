📌 AI+智能体开发比赛

🤖 操作系统AI+智能体开发学习复盘

一、智能体系统验收与设计思路

评价一个Agent系统时，需要关注完整闭环，而不仅是模型输出效果。

  • 输入是什么：明确用户任务、文件、数据来源以及系统接收的信息。
  • 系统执行了什么：说明Agent如何理解任务，调用哪些模型、工具或工作流完成任务。
  • 结果保存在哪里：明确生成内容、结构化数据或执行状态的存储位置。
  • 如何验证成功：通过运行日志、结果文件、接口返回、任务状态等方式验证系统是否达到预期。

    • 核心思想：一个完整Agent不仅需要“能回答”，还需要“可执行、可追踪、可验证”。

    二、智能写作系统核心架构

  • 用户上传本地素材，系统首先进行多格式文档解析。
  • 解析过程中提取标题、正文、表格、图片等结构信息，将非结构化数据转化为可处理内容。
  • 当知识规模较大时，引入RAG架构： 对文档进行Chunk切分，生成Embedding向量并建立索引。
  • 用户提出需求后，通过向量检索找到相关知识片段，并结合引用来源构造增强上下文。
  • 将用户需求、检索结果以及任务要求共同输入大模型，生成符合要求的文本内容。
  • 通过编辑器插件、应用SDK或者Agent工具，将生成结果写入目标文档，实现自动化办公。

    • 关键价值：

  • 减少模型幻觉，提高生成内容的准确性。
  • 利用企业内部知识库，让模型具备领域能力。
  • 通过引用来源增强结果可信度。

    • 同时需要关注数据安全：

  • 采用本地部署或私有化方案，保证敏感数据不离开本地环境。
  • 限制模型访问范围，避免数据泄露。

    • 三、智能办公Agent核心设计

    智能办公系统区别于普通问答系统，更强调任务执行能力。

  • 采用Agent闭环模式： 任务规划 → 工具调用 → 获取反馈 → 调整计划 → 完成任务。
  • 通过“计划一步，执行一步”的方式，让Agent根据执行结果动态调整，而不是一次性生成固定流程。
  • 构建完整可观察链路： 记录任务状态、模型调用、工具调用、执行结果等信息。
  • 根据工具风险等级划分权限： 普通查询可以自动执行，高风险操作需要权限确认。
  • 保存完整日志，方便审计、调试和问题定位。

    • 核心目标： 让Agent具备自主执行能力，同时保证过程透明、安全、可控。

    四、MCP（Model Context Protocol）模型上下文协议

    MCP是一种连接大模型与外部工具、数据源、应用系统的标准化协议。

    它解决的问题：

  • 模型如何稳定调用外部能力。
  • 工具如何统一描述输入输出格式。
  • Agent如何安全访问外部资源。

    • 常见应用：

  • 定义工具能力，让模型知道有哪些工具可以调用。
  • 规范工具参数和返回结果。
  • 连接本地文件、数据库、API等外部资源。
  • 结合权限控制和日志记录，实现安全调用。

    • 理解： MCP相当于给大模型提供了一套标准“接口层”，让模型能够可靠地使用外部世界的能力。

    五、Skill能力模块设计

    Skill是Agent中的可复用能力单元，用于封装具体业务能力。

  • 将任务流程、输入输出格式、执行条件进行标准化封装。
  • 提高Agent能力复用性，避免每次重新设计流程。

    • 常见Skill：

  • 文档总结。
  • 表格数据抽取。
  • 代码生成。
  • 网页信息检索。

    • 多个Skill可以组合形成更复杂的Agent工作流，提高系统扩展能力。

    六、本节总结

    本阶段学习重点是理解企业级Agent系统的整体设计思路：

  • RAG负责增强知识获取能力，让模型能够利用外部知识。
  • MCP负责连接模型与工具，实现标准化调用。
  • Skill负责封装复用能力，提高Agent扩展性。
  • Agent工作流负责任务规划、执行和反馈闭环。

    • 最终目标是构建一个具备知识增强、工具调用、自主执行、安全可控能力的智能体系统。

    📖 第一章 第一节：素质教育与新课改教育观复盘

    一、素质教育的内涵（高频考点）

    素质教育是以提高国民素质为根本宗旨，以促进学生全面发展为核心，培养学生创新精神和实践能力的教育。

  • 面向全体学生： 教育对象不是少数优秀学生，而是所有学生。
  • 促进学生全面发展： 关注德、智、体、美、劳等方面协调发展。
  • 促进学生个性发展： 尊重学生差异，因材施教，发展学生特长。
  • 培养创新精神和实践能力： 重视学生主动探索、解决问题和实际应用能力。

    • 核心：

  • 根本宗旨：提高国民素质。
  • 重点：培养创新精神和实践能力。
  • 灵魂：创新精神。

    • 二、新课改下的教育观（选择题、材料题高频）

    1. 教育从“以教师为中心”转向“以学生发展为中心”

  • 关注学生的主体地位，调动学生学习主动性。
  • 由知识传授者转变为学生学习的促进者和引导者。

    • 材料关键词：

  • 尊重学生主体性。
  • 鼓励自主学习。
  • 关注学生发展需求。

    • 2. 教育从“重结果”转向“重发展”

  • 不仅关注学生成绩，还关注学生能力、兴趣和综合素质发展。
  • 关注学生成长过程中的变化。

    • 材料关键词：

  • 促进学生全面发展。
  • 发展性评价。
  • 不以成绩作为唯一标准。

    • 3. 教育从“关注学科知识”转向“关注学生能力培养”

  • 不仅传授知识，还培养学生创新能力、实践能力和解决问题能力。

    • 材料关键词：

  • 探究学习。
  • 实践活动。
  • 综合能力培养。

    • 4. 教育从“统一标准”转向“尊重个体差异”

  • 承认学生之间存在差异，实施因材施教。

    • 材料关键词：

  • 分层教学。
  • 个性化指导。
  • 发现学生特长。

    • 三、新课改提倡的教育方式（教学方式）

    1. 自主学习

  • 学生主动参与学习过程，发挥主体作用。

    • 关键词： 主动探索、自我学习、自我管理。

    2. 合作学习

  • 通过小组合作、交流讨论共同完成学习任务。

    • 关键词： 小组讨论、团队合作、交流互动。

    3. 探究学习

  • 学生通过发现问题、提出问题、分析问题、解决问题获取知识。

    • 关键词： 问题情境、实践探究、发现规律。

    四、材料题判断重点

    出现以下行为 → 对应考点：

  • 教师只关注成绩排名、忽视学生其他发展 → 违背素质教育全面发展理念。
  • 教师采用灌输式教学，不让学生思考 → 违背学生主体性，未体现新课改理念。
  • 教师鼓励学生讨论、实验、探究 → 体现自主、合作、探究学习方式。
  • 教师根据学生特点安排不同任务 → 体现因材施教和个性发展。
  • 教师评价学生不仅看成绩，还关注能力和进步 → 体现发展性评价。

    • 本节总结

    本节重点掌握素质教育的核心内涵、新课改下教育观以及倡导的教学方式。选择题重点考查概念对应关系，材料分析题重点识别教师行为是否体现“学生主体、全面发展、创新实践、个性培养”等教育理念。
