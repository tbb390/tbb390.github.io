📌 教资科二

📖 第三章：中学教学（第一、二节）

教学概述

教学是在国家教育目的规范下，由教师的教和学生的学共同组成的双边活动，是学校实现教育目的的基本途径。

教学与教育是部分与整体的关系，教学是实施教育的基本途径；教学与智育是交叉关系，智育是教学的重要内容，教学也是实现智育的重要途径。

教学的意义

  • 教学是传播系统知识、促进学生发展的最有效形式。
  • 教学是实施全面发展教育、实现培养目标的基本途径。
  • 教学是学校工作的中心环节。

    • 我国现阶段教学任务（简答重点）

  • 首要任务：使学生掌握系统的现代科学基础知识和基本技能，即“双基”。
  • 发展学生智能，重点培养创造能力和实践能力。
  • 增强学生体质，促进身体健康发展。
  • 培养科学世界观、思想品德、审美情趣和心理素质。

    • 教学过程的本质

    教学过程本质上是一种认识过程，但又是一种特殊的认识过程。

  • 间接性：学生主要学习前人积累的间接经验。
  • 引导性：在教师指导下进行认识活动。
  • 简捷性：通过教学活动快速获得知识经验。
  • 教育性：知识传授与思想品德培养相结合。

    • 教学过程的基本规律（高频考点）

  • 直接经验与间接经验相统一：学生以学习间接经验为主，同时需要结合实践。
  • 掌握知识与发展能力相统一：知识学习是能力发展的基础，能力发展促进知识掌握。
  • 教师主导与学生主体相统一：教师发挥引导作用，学生发挥主体作用。
  • 传授知识与思想教育相统一：教学过程中同时实现知识传授和品德培养。

    • 教学过程的基本结构（简答重点）

  • 引发学习动机：教学过程的起始阶段，激发学生学习兴趣。
  • 领会知识：教学过程的中心环节，包括感知教材和理解教材。
  • 巩固知识：加强记忆，使知识稳定掌握。
  • 运用知识：通过实践解决问题，实现知识迁移。
  • 检查知识：了解学习效果，及时调整教学。

    • 本节备考重点

    本节重点掌握教学的概念及其与教育、智育的关系，熟记我国现阶段教学任务；教学过程重点理解“特殊认识过程”的特点、四大教学规律以及教学过程五个基本环节，是选择题、辨析题、简答题和材料分析题的重要考点。

    📌 深度学习（李宏毅课程）

    🧠 Regression：Case Study（回归案例）

    Regression（回归）任务概念

    李宏毅老师通过 Regression 案例引入机器学习的基本思想：机器学习的本质就是让计算机从数据中自动寻找一个函数（Function），通过输入特征 x 预测输出结果 y。

  • Regression 的目标是预测连续数值，例如房价预测、股价预测、自动驾驶方向控制、推荐系统评分预测等。
  • 与分类任务不同，回归输出的是具体数值，而不是类别。

    • 案例：预测宝可梦进化后的 CP 值

    课程通过预测宝可梦进化后的 CP 值，展示机器学习解决实际问题的流程。

  • 输入（x）：宝可梦当前的各种属性，例如攻击、防御、速度等特征。
  • 输出（y）：宝可梦进化后的 CP 值。
  • 由于训练数据中包含“属性 → CP值”的对应关系，因此属于监督学习问题。

    • 机器学习的目标就是找到一个函数，使预测结果尽可能接近真实答案。

    机器学习三步骤（核心框架）

    ① Model（选择模型）

    第一步是选择一个函数形式，也就是定义模型。例如最简单的线性模型：

  • 通过权重 w 和偏置 b 调整函数，使模型能够描述输入和输出之间的关系。
  • 不同的参数组合代表不同的函数，机器学习就是在这些函数中寻找最合适的一个。

    • ② Loss Function（定义评价标准）

    模型预测后，需要判断预测结果是否准确，因此需要定义损失函数（Loss Function）。

  • 回归任务常使用均方误差（MSE），计算预测值与真实值之间的差距。
  • Loss 越小，说明模型预测效果越好。

    • ③ Optimization（优化参数）

    确定模型和损失函数后，需要寻找使 Loss 最小的参数组合。

  • 常用方法是梯度下降（Gradient Descent）。
  • 梯度表示 Loss 增长最快的方向，因此参数更新时需要沿梯度相反方向移动。
  • 通过不断调整参数，使模型逐渐接近最佳状态。

    • 梯度下降关键概念

  • 学习率（Learning Rate）：控制每次参数更新的步长。
  • 学习率过大：可能导致模型在最优点附近震荡，无法收敛。
  • 学习率过小：训练速度过慢，需要更多迭代次数。

    • 模型复杂度与过拟合（Overfitting）

    为了提高模型预测能力，可以增加更多特征或使用更复杂的模型，但模型并不是越复杂越好。

  • 模型过于简单：无法学习数据规律，称为欠拟合。
  • 模型过于复杂：会记住训练数据中的噪声，导致训练集表现很好，但面对新数据效果较差，这就是过拟合。
  • 机器学习不仅要求拟合训练数据，更重要的是具备泛化能力。

    • 解决过拟合：Regularization（正则化）

    正则化通过在损失函数中加入惩罚项，限制模型参数过大，从而降低模型复杂度。

  • 目的：让模型更加平滑，减少对训练数据噪声的依赖，提高泛化能力。
  • λ（正则化参数）控制惩罚强度。
  • λ 太小：限制不足，容易过拟合。
  • λ 太大：模型受到过强限制，可能出现欠拟合。

    • 本节核心总结

    Regression：Case Study 是李宏毅课程中建立机器学习整体框架的重要章节。通过宝可梦 CP 值预测案例，理解了机器学习解决问题的完整流程：选择 Model → 定义 Loss → 使用 Optimization 更新参数。同时掌握了梯度下降、学习率、模型复杂度、过拟合和正则化等核心概念，为后续学习神经网络训练、反向传播和深度学习模型优化奠定基础。
