📖 概率论

📚 今日学习总结（概率论·强化版）

🎯 一、分布函数 F(x)

  • 定义：F(x)=P(X≤x)
  • 性质：单调不减、右连续
  • 范围：0≤F(x)≤1
  • 极限：F(-∞)=0，F(+∞)=1

核心用途：

  • P(a
  • 统一处理概率问题（连续型最常用）
---

🎯 二、离散型随机变量

  • 分布律：P(X=xᵢ)=pᵢ
  • 性质：pᵢ≥0，Σpᵢ=1
  • 本质：用概率描述每个取值

常见题型：

  • 补全分布
  • 验证合法性
  • 求函数分布（Y=g(X)）
---

🎯 三、连续型随机变量

  • 密度函数：f(x)
  • 性质：f(x)≥0
  • 归一条件：∫f(x)dx=1

常见步骤：

  • ① 求未知常数 k
  • ② 求分布函数 F(x)
  • ③ 求概率 P(a
---

🎯 四、常见分布

① 均匀分布 U(a,b)

  • 区间内等概率
  • 概率 = 长度比例

② 正态分布 N(μ,σ²)

  • 钟形对称分布
  • 标准化：Z=(X-μ)/σ
  • 用标准正态表查概率
---

🎯 五、随机变量函数

  • 离散：重新列值 + 概率合并
  • 连续：用分布函数或变量代换
  • 本质：变量变换后的分布问题

关键点：不是“算函数”，而是“重新找分布”

---

🎯 六、二维随机变量

  • 联合分布：描述(X,Y)整体概率结构
  • 联合分布函数：F(x,y)=P(X≤x,Y≤y)

边缘分布：

  • 离散：按行/列求和
  • 连续：积分消元

核心性质：

  • 独立性：P(X,Y)=P(X)P(Y)

第二章 进程管理（中段核心：PV + 线程 + 进程控制）

  • PV操作核心思想
    • P操作（wait）：申请资源，使信号量S = S - 1
    • V操作（signal）：释放资源，使信号量S = S + 1
    • PV操作用于实现：互斥与同步
  • PV操作标准模板（必须掌握）
    • 互斥访问（临界区）
    P(mutex);

// 临界区代码

V(mutex);
    • 生产者消费者模型（必考大题）
    生产者：
P(empty);
P(mutex);

// 放入数据

V(mutex);
V(full);


消费者：
P(full);
P(mutex);

// 取出数据

V(mutex);
V(empty);
    • 信号量含义：
      • mutex：互斥锁（初值1）
      • empty：空缓冲区数量（初值n）
      • full：已有数据数量（初值0）
  • 进程控制（四大原语）
    • 创建：创建PCB + 分配资源
    • 撤销：释放资源 + 删除PCB
    • 阻塞：运行态 → 阻塞态（等待事件）
    • 唤醒：阻塞态 → 就绪态
  • 进程控制核心理解
    • 本质：进程状态的改变 + PCB管理
    • 所有操作围绕进程状态转换进行
  • 线程（Thread）概念
    • 线程是CPU调度的基本单位
    • 进程是资源分配单位
    • 线程共享进程资源（地址空间、文件等）
    • 线程切换开销小于进程
  • 进程 vs 线程）
    • 进程：资源分配单位
    • 线程：CPU调度单位
    • 线程共享进程资源
    • 进程切换开销大，线程切换开销小
  • 线程实现方式
    • 用户级线程：由用户空间管理
    • 内核级线程：由操作系统管理
    • 混合线程：两者结合
    • 考试重点：内核级线程由OS调度
  • 信号（Signal）机制
    • 信号是一种异步通知机制
    • 用于进程间通信或事件通知
    • Ctrl + C 终止进程
  • 第二章核心总结
    • PV操作 = 同步 + 互斥核心（必考大题）
    • 生产者消费者 = PV经典模型
    • 进程控制 = 状态转换 + PCB管理
    • 线程 = CPU调度单位
    • 进程 = 资源分配单位
