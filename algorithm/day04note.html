一、LC70 爬楼梯

题目描述

假设正在爬楼梯，需要爬到第 n 阶。每次可以爬 1 阶或 2 阶， 求到达楼顶一共有多少种不同的方法。

示例
输入：n = 3
输出：3
解释：有三种方法：1+1+1、1+2、2+1。

解题思路

这道题使用一维动态规划。 dp[i] 表示爬到第 i 阶楼梯的不同方案数。

到达第 i 阶，可以从第 i-1 阶爬 1 阶上来， 也可以从第 i-2 阶爬 2 阶上来。 把这两种情况相加

状态转移方程：
dp[i] = dp[i-1] + dp[i-2]

初始条件：dp[1] = 1，dp[2] = 2。
遍历顺序：从 i = 3 开始递推。

代码实现

class Solution {
public:
    int climbStairs(int n) {
        if (n <= 2) return n;

        vector<int> dp(n + 1, 0);

        dp[1] = 1;
        dp[2] = 2;

        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }

        return dp[n];
    }
};

复杂度分析

时间复杂度：O(n) 空间复杂度：O(n)
今天遇到的问题：
1. dp 数组需要先定义，不能直接使用 dp[n]
2. 前两项已经初始化，循环应该从i=3开始
3. 每次应该更新 dp[i]，而不是一直覆盖 dp[n]
4. 最后返回 dp[n]，表示到达第 n 阶的方案。

二、LC62 不同路径

题目描述

一个机器人位于 m × n 网格的左上角， 每次只能向下或者向右移动一步。 求机器人到达右下角一共有多少条不同的路径。

示例
输入：m = 3, n = 7
输出：28

解题思路

这道题从一维 DP 过渡到了二维 DP。 dp[i][j] 表示从左上角出发，到达第 i 行、第 j 列位置的路径总数。

因为机器人只能向右或者向下移动， 所以到达当前位置，只能从上方或者左方过来。

状态转移方程：
dp[i][j] = dp[i-1][j] + dp[i][j-1]

初始化：
第一行全部初始化为 1。
第一列全部初始化为 1。

遍历顺序：从 i = 1、j = 1 开始， 逐行逐列计算。

最终返回：dp[m-1][n-1]。

代码实现

class Solution {
public:
    int uniquePaths(int m, int n) {

        vector<vector<int>> dp(m, vector<int>(n, 0));

        for (int i = 0; i < m; i++) {
            dp[i][0] = 1;
        }
        //初始化第一列


        for (int j = 0; j < n; j++) {
            dp[0][j] = 1;
        }        //初始化第一行

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        return dp[m - 1][n - 1];
    }
};

复杂度分析

时间复杂度：O(m × n) 空间复杂度：O(m × n)
今天遇到的问题：
1. 二维数组使用 vector<vector<int>> 定义。
2. C++ 数组下标从 0 开始，所以右下角是 dp[m-1][n-1]， 不能写成 dp[m][n]。
3. 第一行和第一列已经初始化，因此循环从 1 开始， 不是从 2 开始。
4. 左边的位置应该是 dp[i][j-1]， 不能把行和列下标写反。
5. 最后返回右下角的 DP 值，而不是循环变量 i、j。

三、LC63 不同路径 II

题目描述

在 LC62 的基础上，网格中增加了障碍物。 机器人仍然只能向右或者向下移动， 但是不能经过障碍物，求到达右下角的不同路径数量。

示例
输入：
obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
输出：2
其中 0 表示可以通过，1 表示障碍物。

解题思路

这道题沿用了 LC62 的二维 DP 思路， 但是增加了障碍物判断。

dp[i][j] 表示从起点到达当前位置的有效路径数量。

核心规则：

1. 如果当前位置是障碍物，dp[i][j] = 0。
2. 如果当前位置不是障碍物，路径数仍然是上方加左方。

状态转移：
障碍物：dp[i][j] = 0
普通位置：dp[i][j] = dp[i-1][j] + dp[i][j-1]

起点如果是障碍物，直接返回 0。

边界初始化

LC62 中第一行和第一列都可以直接初始化为 1， 但是 LC63 不行，因为障碍物会阻断后续路径。

第一行只能从左边过来，所以当前格子的路径数继承左边的值。 第一列只能从上边过来，所以当前格子的路径数继承上边的值。

第一行示例
obstacleGrid：[0, 0, 1, 0, 0]
dp：[1, 1, 0, 0, 0]

障碍物后面的格子虽然本身可以通过， 但是已经无法从起点到达，所以路径数量仍然为 0。

代码实现

class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {

        int m = obstacleGrid.size();
        int n = obstacleGrid[0].size();

        vector<vector<int>> dp(m, vector<int>(n, 0));

        if (obstacleGrid[0][0] == 1) {
            return 0;
        }

        dp[0][0] = 1;

        for (int i = 1; i < m; i++) {
            if (obstacleGrid[i][0] == 1) {
                dp[i][0] = 0;
            } else {
                dp[i][0] = dp[i - 1][0];
            }
        }

        for (int j = 1; j < n; j++) {
            if (obstacleGrid[0][j] == 1) {
                dp[0][j] = 0;
            } else {
                dp[0][j] = dp[0][j - 1];
            }
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {

                if (obstacleGrid[i][j] == 1) {
                    dp[i][j] = 0;
                } else {
                    dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
                }
            }
        }

        return dp[m - 1][n - 1];
    }
};

复杂度分析

时间复杂度：O(m × n) 空间复杂度：O(m × n)
今天遇到的问题：
1. 障碍物位置的 DP 值是 0，不是 1。
2. 障碍物会阻断后续路径，不能只把障碍物本身设为 0。
3. 第一行要根据左边的位置初始化。
4. 第一列要根据上边的位置初始化。
5. 中间位置先判断是否为障碍物，再决定是否执行状态转移。

四、三道题的联系与区别

LC70：一维 DP
当前状态由前面两个状态推导出来。

LC62：二维 DP
当前格子的路径数由上方和左方两个状态推导出来。

LC63：带障碍物的二维 DP
保留 LC62 的基本转移思路，增加障碍物判断和边界处理。
